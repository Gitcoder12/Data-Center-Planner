# Contributing to Data-Center-Planner

1. Read README.md, ACTIVITY_LOG.md and FEATURE_UPGRADE_PLAN.md.
2. Choose one bounded schema, formula or simulation task.
3. Work on a feature branch.
4. Use deterministic fixtures and state units/seed/thresholds.
5. Add tests for normal, boundary and invalid configuration.
6. Never use simulated outputs to claim real-world safety or facility approval.
7. Open a PR with exact test commands and results.

Human review is required for any real facility data or engineering decision claims.
